classmethod init(num_devices='auto', *, device=None, verbose=True, force=True)[源代码]

Elegant one-line initialization for parallel MCMC chains.

参数:

  • num_devices (int, 'auto', or None) – Number of parallel devices (= number of parallel chains): - int: Use N devices for N parallel chains (e.g., init(8) for 8 chains) - ‘auto’: Auto-detect optimal device count (default) - None: Use single device (vectorized mode) - ‘GPU’ / ‘cuda’: GPU auto-detect and configure

  • device (str or None) – Explicit device selection (overrides num_devices if ‘GPU’): - None (default): CPU mode - ‘GPU’ / ‘cuda’: GPU auto-detect and configure

  • verbose (bool) – Whether to show initialization messages

  • force (bool) – Force override existing XLA_FLAGS (default True for user convenience)

返回:

True if successful, False otherwise

返回类型:

bool

示例

>>> # 8 parallel chains (most common usage)
>>> Config.init(8)

>>> # Auto configuration
>>> Config.init()

>>> # Silent initialization with 4 chains
>>> Config.init(4, verbose=False)

>>> # GPU auto configuration
>>> Config.init("GPU")

class hicosmo.samplers.MCMC(config, likelihood_func, strict_mode=False, chain_name=None, likelihoods=None, sampler='numpyro', chain_method='auto', optimize_init=False, max_opt_iterations=1000, opt_learning_rate=0.01, enable_checkpoints=True, checkpoint_interval=1000, checkpoint_interval_seconds=600.0, checkpoint_dir=PosixPath('mcmc_chains'), backup_versions=5, save_warmup=True, compression='gzip', auto_resume=True, **data_kwargs)[源代码]

基类：object

MCMC sampling with intelligent parameter management and multi-sampler support.

This class provides a qcosmc-style simple API while supporting multiple MCMC backends (NumPyro NUTS, emcee, etc.). It automatically handles parameter mapping, model generation, MCMC sampling, and comprehensive data persistence.

Supported samplers: - ‘numpyro’ (default): NumPyro NUTS (fast, gradient-based, JAX-compatible) - ‘emcee’: Ensemble sampler (robust, no gradients needed, handles NaN/Inf gracefully)

示例

>>> # Dictionary-based configuration (recommended)
>>> config = {
...     'parameters': {
...         'H0': {
...             'prior': {'dist': 'uniform', 'min': 50, 'max': 100},
...             'ref': 70.0,
...             'latex': r'H_0'
...         },
...         'Omega_m': {
...             'prior': {'dist': 'normal', 'loc': 0.3, 'scale': 0.05},
...             'bounds': [0.1, 0.5]
...         }
...     },
...     'mcmc': {'num_samples': 4000, 'num_chains': 4}  # 4000 total samples
... }

# Note: num_samples represents TOTAL samples across all chains. # With 4 chains, this will be 1000 samples per chain (4000/4=1000).

>>> def my_likelihood(H0, Omega_m, sn_data):
...     # Your likelihood computation
...     return log_likelihood_value

>>> # One-line MCMC with automatic checkpointing
>>> mcmc = MCMC(config, my_likelihood, sn_data=supernova_data)
>>> results = mcmc.run()
>>> mcmc.print_summary()

>>> # Simple list format (qcosmc-compatible)
>>> params = [
...     ['H0', 70, 50, 100],
...     ['Omega_m', 0.3, 0.1, 0.5]
... ]
>>> mcmc = MCMC.from_simple_list(params, my_likelihood, sn_data=data)

classmethod resume(checkpoint_path, likelihood_func=None, strict_validation=True, **new_kwargs)[源代码]

Resume MCMC from a checkpoint file.

备注

If the checkpoint contains backend internal state (NumPyro/NUTS), this performs a true continuation from the last state. Otherwise, new samples will be appended after the existing samples.

参数:

  • checkpoint_path (str or Path) – Path to checkpoint file to resume from

  • likelihood_func (Callable, optional) – Likelihood function. If None, will try to resume with saved info.

  • strict_validation (bool) – Whether to enforce strict compatibility validation

  • **new_kwargs – New configuration options that override saved settings

classmethod from_dict(data)[源代码]

Create ParameterConfig from dictionary.

Supports both nested and flat dictionary formats:

Nested format (with ‘parameters’ key): {

‘parameters’: {

‘a’: {‘prior’: {‘dist’: ‘uniform’, ‘min’: 0, ‘max’: 10}, ‘ref’: 3.5}

}, ‘mcmc’: {‘num_samples’: 1000}

}

Flat format (parameters at top level): {

‘a’: {‘prior’: {‘dist’: ‘uniform’, ‘min’: 0, ‘max’: 10}, ‘ref’: 3.5}, ‘mcmc’: {‘num_samples’: 1000}

}

Simplified tuple/list/set format: {

‘parameters’: {

‘a’: (3.5, 0, 10, ‘$a$’), # or [3.5, 0, 10] or {3.5, 0, 10, ‘$a$’} ‘b’: [2.0, 0, 4, ‘$b$’]

}

}

参数:

data (Dict[str, Any])

返回类型:

ParameterConfig
