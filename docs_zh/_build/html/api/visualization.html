HIcosmo Visualization System

Unified API for cosmological parameter visualization.

Recommended Usage - Plotter Class (3 lines): ```python from hicosmo.visualization import Plotter

plotter = Plotter(‘results/mcmc_chain.pkl’) plotter.corner([‘H0’, ‘Omega_m’], filename=’corner.pdf’) ```

Multi-chain Comparison: `python plotter = Plotter([data1, data2], chain_labels=['Planck', 'SH0ES']) plotter.corner(['H0', 'Omega_m'], filename='comparison.pdf') `

Fisher Forecasts: `python plotter = Plotter.from_fisher(mean, cov, param_names=['w0', 'wa']) plotter.corner(filename='forecast.pdf') `

Function Interface (backward compatible): ```python from hicosmo.visualization import plot_corner

fig = plot_corner(‘chains/data.pkl’, params=[‘H0’, ‘Omega_m’], filename=’corner.pdf’) ```

Author: Jingzhao Qi

class hicosmo.visualization.Plotter(data, *, labels=None, ranges=None, chain_labels=None, style='modern', results_dir='results', **kwargs)[源代码]

基类：object

HIcosmo unified visualization interface.

Supports multiple data input formats: - Chain name: ‘my_chain’ (auto-loads from mcmc_chains/my_chain.h5) - Chain names list: [‘chain1’, ‘chain2’] (multi-chain mode) - Dict: {‘H0’: arr, ‘Omega_m’: arr} - NumPy array: np.array((N, D)) - MCSamples: GetDist native object

示例

>>> # Single chain (simplest!)
>>> plotter = Plotter('my_chain')
>>> plotter.corner(['H0', 'Omega_m'], filename='corner.pdf')

>>> # Multi-chain comparison
>>> plotter = Plotter(
...     ['low_noise', 'high_noise'],
...     labels=['Low Noise', 'High Noise']
... )
>>> plotter.corner(['a', 'b', 'c'], filename='comparison.pdf')

>>> # From dict
>>> plotter = Plotter({'H0': samples_h0, 'Omega_m': samples_om})

>>> # Fisher forecast
>>> plotter = Plotter.from_fisher(mean, cov, param_names=['w0', 'wa'])

hicosmo.visualization.aic(log_likelihood_max, num_params, normalization_constant=0.0)[源代码]

Compute Akaike Information Criterion.

参数:

  • log_likelihood_max (float) – Maximum log-likelihood value from MCMC samples.

  • num_params (int) – Number of free parameters (k).

  • normalization_constant (float, optional) – Log-likelihood normalization constant. If provided, the AIC is computed from chi-squared: AIC = χ²_min + 2k where χ² = -2*(logL - normalization). Default is 0.0 (no normalization correction).

返回:

AIC = χ²_min + 2k = 2k - 2*(log_likelihood_max - normalization_constant)

返回类型:

float

备注

The standard formula AIC = 2k - 2*ln(L_max) assumes log_likelihood doesn’t include normalization constants. When likelihood includes normalization (e.g., -0.5*log|C| for Gaussian), provide that constant to get correct AIC.

hicosmo.visualization.bic(log_likelihood_max, num_params, num_data, normalization_constant=0.0)[源代码]

Compute Bayesian Information Criterion.

参数:

  • log_likelihood_max (float) – Maximum log-likelihood value from MCMC samples.

  • num_params (int) – Number of free parameters (k).

  • num_data (int) – Number of data points (N).

  • normalization_constant (float, optional) – Log-likelihood normalization constant. If provided, the BIC is computed from chi-squared: BIC = χ²_min + k*ln(N). Default is 0.0 (no normalization correction).

返回:

BIC = χ²_min + k*ln(N) = k*ln(N) - 2*(log_likelihood_max - normalization_constant)

返回类型:

float

备注

The standard formula BIC = k*ln(N) - 2*ln(L_max) assumes log_likelihood doesn’t include normalization constants. Provide the normalization constant to get correct BIC values.

Compute AIC, BIC, and log evidence from MCMC results.

参数:

  • samples (various, optional) – MCMC samples (dict, array, SamplerResults/MCMCState, chain name, or file path).

  • log_likelihoods (array-like, optional) – Log-likelihood values for samples. Required if log_likelihood_fn is not provided.

  • log_likelihood_fn (callable, optional) – Function that evaluates log-likelihood. Accepts kwargs or a dict.

  • num_params (int, optional) – Number of free parameters. If None, inferred from parameter_config or samples.

  • num_data (int, optional) – Number of data points for BIC. If None, BIC is omitted.

  • param_names (sequence of str, optional) – Parameter names to use when evaluating log_likelihood_fn.

  • log_likelihood_key (str, optional) – Key for log-likelihood stored in samples dict.

  • burnin_frac (float, optional) – Fraction of samples to discard as burn-in.

  • thin (int, optional) – Thinning factor.

  • max_samples (int, optional) – Cap on the number of samples used for evaluation.

  • evidence_method (str or None, optional) – Evidence estimator (“harmonic_mean”). Set to None to skip.

  • parameter_config (optional) – ParameterConfig or dict to infer num_params and free parameter names.

  • data_info (mapping, optional) – Data metadata to infer num_data.

返回类型:

Dict[str, float | None]

备注

If samples include derived parameters, pass num_params, param_names, or parameter_config to avoid over-counting parameters.
