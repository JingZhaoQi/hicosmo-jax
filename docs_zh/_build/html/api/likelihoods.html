似然 API

包含 SN / BAO / CMB / H0LiCOW / GW 等似然接口。

主入口

HIcosmo Likelihood System

Clean, minimal likelihood implementations following CLAUDE.md design principles.

Submodules: - bao/: Baryon Acoustic Oscillations - sn/: Type Ia Supernovae - cmb/: Cosmic Microwave Background - h0/: Direct H0 measurements - gw/: Gravitational Wave Standard Sirens - lensing/: Strong Gravitational Lensing

Quick Start:
>>> from hicosmo.likelihoods import SN_likelihood, BAO_likelihood
>>> from hicosmo.models import LCDM
>>> sne = SN_likelihood(LCDM, "pantheon+", M_B="free")
>>> bao = BAO_likelihood(LCDM, "desi2024")
>>> log_L = sne(H0=70, Omega_m=0.3, M_B=-19.3) + bao(H0=70, Omega_m=0.3)
Discover Available Datasets:
>>> from hicosmo.likelihoods import list_all_datasets, show_available_datasets
>>> list_all_datasets()  # Returns dict of all available datasets
>>> show_available_datasets()  # Pretty print all datasets

class hicosmo.likelihoods.DESI2024BAO(cosmology_class=None, omega_b_mode='free', **kwargs)[源代码]

基类：BAOLikelihood

DESI 2024 BAO measurements (Data Release 1).

Reference: DESI Collaboration 2024 (arXiv:2404.03002)

参数:

  • cosmology_class (type, optional) – Cosmology model class (LCDM, wCDM, etc.). Default is LCDM.

  • omega_b_mode (str, default 'free') –

    How to handle baryon density Omega_b: - ‘free’: Sample Omega_b freely (uniform prior 0.03-0.07).

    BAO alone will only constrain H0*r_d, not H0 separately. This is the physically correct default matching DESI official analysis.

    • ’bbn_prior’: Sample Omega_b with BBN prior (Omega_b*h^2 = 0.02218 ± 0.00055). Omega_b is registered as nuisance parameter.

    • ’fixed’: Use Planck 2018 value (Omega_b = 0.0493). This implicitly breaks the H0-r_d degeneracy (not recommended for BAO-only analysis).

备注

BAO measurements constrain D_M/r_d and D_H/r_d, where r_d depends on Omega_b. DESI BAO alone can only constrain H0*r_d (Eq. 4.1 in arXiv:2404.03002). To constrain H0 independently, external information on Omega_b is needed (BBN prior or CMB).

示例

>>> # Standard analysis with fixed Omega_b (Planck value)
>>> bao = BAO_likelihood(LCDM, "desi2024", omega_b_mode='fixed')
>>>
>>> # With BBN prior on Omega_b
>>> bao = BAO_likelihood(LCDM, "desi2024", omega_b_mode='bbn_prior')
>>>
>>> # BAO-only (will output r_d*h as derived parameter)
>>> bao = BAO_likelihood(LCDM, "desi2024", omega_b_mode='free')

External lens likelihood for SLACS/SL2S samples.

These lenses provide kinematic constraints only (no time-delay distances). They help break the H0-λ_int degeneracy by constraining λ_int independently.

Physics: - σ²_model = c² × J × (D_s/D_ds) × λ_int × kin_scaling - D_s/D_ds depends only on Ω_m (NOT H0!) - So by fitting σ_obs, we constrain λ_int without constraining H0 - Combined with time-delay lenses (which constrain H0 × λ_int), we break degeneracy

get_normalization_constant()[源代码]

Return the log-likelihood normalization constant.

The normalization constant is the portion of log-likelihood that does NOT depend on model parameters. For Gaussian likelihoods:

log(L) = -χ²/2 + normalization_constant

where the normalization constant typically includes: - -0.5 * log|C| (covariance determinant) - -N/2 * log(2π) (Gaussian prefactor, often omitted) - Other data-dependent constants

This constant is needed for information criteria (AIC, BIC) which use χ²:

χ² = -2 * (log_likelihood - normalization_constant) AIC = χ²_min + 2k BIC = χ²_min + k * ln(N)

class hicosmo.likelihoods.bao.DESI2024BAO(cosmology_class=None, omega_b_mode='free', **kwargs)[源代码]

DESI 2024 BAO measurements (Data Release 1).

Reference: DESI Collaboration 2024 (arXiv:2404.03002)

参数:

  • cosmology_class (type, optional) – Cosmology model class (LCDM, wCDM, etc.). Default is LCDM.

  • omega_b_mode (str, default 'free') –

    How to handle baryon density Omega_b: - ‘free’: Sample Omega_b freely (uniform prior 0.03-0.07).

    BAO alone will only constrain H0*r_d, not H0 separately. This is the physically correct default matching DESI official analysis.

    • ’bbn_prior’: Sample Omega_b with BBN prior (Omega_b*h^2 = 0.02218 ± 0.00055). Omega_b is registered as nuisance parameter.

    • ’fixed’: Use Planck 2018 value (Omega_b = 0.0493). This implicitly breaks the H0-r_d degeneracy (not recommended for BAO-only analysis).

备注

BAO measurements constrain D_M/r_d and D_H/r_d, where r_d depends on Omega_b. DESI BAO alone can only constrain H0*r_d (Eq. 4.1 in arXiv:2404.03002). To constrain H0 independently, external information on Omega_b is needed (BBN prior or CMB).

示例

>>>
>>> # With BBN prior on Omega_b
>>> bao = BAO_likelihood(LCDM, "desi2024", omega_b_mode='bbn_prior')
>>>
>>> # BAO-only (will output r_d*h as derived parameter)
>>> bao = BAO_likelihood(LCDM, "desi2024", omega_b_mode='free')
