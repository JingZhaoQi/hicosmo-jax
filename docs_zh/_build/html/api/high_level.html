hicosmo.hicosmo.hicosmo(cosmology, likelihood, free_params, preset='planck2018', num_samples=8000, num_chains=4, strict_mode=False, **mcmc_kwargs)[源代码]

Create cosmological parameter inference with zero configuration.

This is the main high-level API for HIcosmo. It automatically: - Loads parameter defaults from presets (Planck 2018, WMAP9, etc.) - Sets specified parameters as free, others as fixed - Handles nuisance parameters (e.g., M_B marginalization) - Combines multiple likelihoods - Configures MCMC sampling

cosmologyType[CosmologyBase] or str

Cosmology model CLASS (not instance) or string name. Examples: LCDM, wCDM, CPL or ‘LCDM’, ‘wCDM’, ‘CPL’

likelihoodLikelihood, List[Likelihood], or str

Single likelihood object/string or list of likelihood objects/strings. Supported string shortcuts: - Supernovae: ‘sn’, ‘sn_shoes’ - BAO: ‘bao’, ‘bao_sdss_dr12’, ‘bao_sdss_dr16’, ‘bao_boss_dr12’, ‘bao_sixdf’ - Strong Lensing: ‘h0licow’, ‘tdcosmo’ - CMB: ‘planck’, ‘planck2018’, ‘cmb’ - H0: ‘shoes’, ‘sh0es’, ‘h0’ Each likelihood must have a log_likelihood() method.

free_paramsList[str]

List of parameter names to vary in MCMC sampling. Example: [‘H0’, ‘Omega_m’]

presetstr, default=’planck2018’

Parameter preset name for default values. Options: ‘planck2018’, ‘wmap9’

num_samplesint, default=8000

Total number of MCMC samples (across all chains).

num_chainsint, default=4

Number of parallel MCMC chains.

strict_modebool, default=False

If True, raise errors for parameter mismatches. If False, issue warnings and attempt auto-correction.

**mcmc_kwargs

Additional MCMC configuration parameters. Examples: num_warmup, target_accept, max_tree_depth

InferenceRunner

Inference execution object. Call .run() to execute sampling.

>>> # Ultra-simple string-based inference
>>> from hicosmo import hicosmo
>>>

>>> inference = hicosmo(
...     cosmology='LCDM',
...     likelihood='sn',
...     free_params=['H0', 'Omega_m']
... )
    >>> samples = inference.run()

>>> # Traditional class-based inference
>>> from hicosmo.models import LCDM

>>> from hicosmo.likelihoods import SN_likelihood
    >>>
>>> inference = hicosmo(
...     cosmology=LCDM,
...     likelihood=SN_likelihood(LCDM, "pantheon+"),
...     free_params=['H0', 'Omega_m']
... )
    >>> samples = inference.run()

>>> # Multi-probe joint analysis

>>> inference = hicosmo(
...     cosmology='LCDM',
...     likelihood=['sn_shoes', 'bao', 'cmb'],
...     free_params=['H0', 'Omega_m'],
...     num_samples=16000,
...     num_chains=8
... )
    >>> samples = inference.run()

class hicosmo.hicosmo.InferenceRunner(cosmology_class, likelihoods, registry, mcmc_config, setup_mcmc=True)[源代码]

High-level inference execution wrapper.

This class encapsulates the complete MCMC workflow with automatic parameter matching, likelihood combination, and cosmology model instantiation.

Users should create instances via the hicosmo() factory function rather than directly instantiating this class.

参数:

  • registry (ParameterRegistry)

run(num_samples=None, num_chains=None, **kwargs)[源代码]

Run MCMC sampling.

参数:

  • **kwargs – Additional MCMC parameters (e.g., num_warmup, target_accept).
