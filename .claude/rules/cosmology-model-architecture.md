# Cosmology Model Architecture Rules

Rules for creating and maintaining cosmological models in HIcosmo.

## 1. Minimal Subclass Principle

**Subclasses only define: differential physics + necessary parameters**

| Must Define | Optional | Never Define |
|-------------|----------|--------------|
| `__init__` | `w_z()` (if different) | `_E_z_static` |
| `@staticmethod E_z(z, params)` | `get_parameters()` (if new params) | Factory methods |
| | | Distance calculations |

```python
# ✅ CORRECT: Minimal subclass
@register_cosmology_model
class wCDM(LCDM):
    def __init__(self, w=-1.0, **kwargs):
        super().__init__(w=w, **kwargs)

    @staticmethod
    def E_z(z, params):
        # Only the physics that differs from LCDM
        ...

# ❌ WRONG: Redefining base class methods
class wCDM(LCDM):
    def _E_z_static(self, z, params): ...  # Don't need!
    def compute_grid_traced(self, ...): ...  # Don't need!
```

## 2. Unified Signature Principle

**All core computation functions use: `func(z, params)`**

Benefits:
- Base class provides generic implementations
- Decorators handle uniformly
- Reduces parameter passing errors

```python
# ✅ Unified signature
@staticmethod
def E_z(z, params):
    Omega_m = params['Omega_m']
    w = params.get('w', -1.0)
    ...

# ❌ Expanded parameters (hard to extend)
@staticmethod
def E_z(z, Omega_m, Omega_r, Omega_k, Omega_Lambda, w):
    ...
```

## 3. User-First Naming Principle

**Public API uses intuitive names; internal details use prefixes**

| Level | Name | Purpose |
|-------|------|---------|
| User API | `E_z(z, params)` | Define model physics |
| Instance method | `model.E_z(z)` | Daily usage |
| Internal | `_E_z_kernel` | Decorator use |
| JIT compiled | `_E_z_static` | MCMC sampling |

Users write `E_z` when building models - they don't need to know `_E_z_kernel` exists.

## 4. Decorator Generation Principle

**Boilerplate code auto-generated by decorators, not manually copied**

`@register_cosmology_model` auto-generates:
- `_E_z_kernel` ← from user's `E_z`
- `_E_z_static` ← JIT compiled version
- `E_z(self, z)` ← instance method wrapper
- `compute_grid_traced` ← MCMC factory method
- `sound_horizon_traced` etc.

Benefits:
- Zero boilerplate for new models
- Modify once, apply globally
- Avoid copy-paste errors

## 5. Physics-Framework Separation

**Physics formulas in subclass, framework logic in base/decorator**

```python
# Subclass: Pure physics only
@register_cosmology_model
class CPL(LCDM):
    @staticmethod
    def E_z(z, params):
        # Pure physics: w(z) = w0 + wa * z/(1+z)
        f_DE = jnp.exp(3*wa*z/(1+z)) * (1+z)**(3*(1+w0+wa))
        return jnp.sqrt(Omega_m*(1+z)**3 + Omega_Lambda*f_DE)

# Base/Decorator: Framework logic (JIT, traced, distances, etc.)
```

## 6. Backward Compatibility

**New API coexists with old API for gradual migration**

Decorator supports both:
- New: `@staticmethod E_z(z, params)`
- Old: `_E_z_kernel(z, params)`

```python
# Decorator detects both patterns
if 'E_z' in cls.__dict__ and isinstance(cls.__dict__['E_z'], staticmethod):
    # New API
    E_z_static_func = cls.__dict__['E_z'].__func__
elif hasattr(cls, '_E_z_kernel'):
    # Old API (backward compatible)
    E_z_static_func = cls._E_z_kernel
```

## 7. Lines of Code as Design Quality Metric

| Model | Before | After | Reduction |
|-------|--------|-------|-----------|
| wCDM | ~150 | 62 | **59%** |
| CPL | ~180 | 77 | **57%** |
| ILCDM | ~200 | 100 | **50%** |

**Rule**: If subclass exceeds 100 lines, design is flawed - move common logic to base class or decorator.

## New Model Checklist

When creating a new cosmological model:

- [ ] Inherit from `LCDM` (or closer parent)
- [ ] Use `@register_cosmology_model` decorator
- [ ] Define `@staticmethod E_z(z, params)` returning E(z)
- [ ] Only override `w_z()` if necessary
- [ ] Only override `get_parameters()` if new parameters exist
- [ ] **DO NOT** manually define `_E_z_static`, `compute_grid_traced`, etc.

## Example: Creating a New Model

```python
from typing import Dict, Union
import jax.numpy as jnp
from .lcdm import LCDM
from .base import register_cosmology_model

@register_cosmology_model
class MyNewModel(LCDM):
    """My custom dark energy model."""

    def __init__(self, my_param: float = 0.0, **kwargs):
        super().__init__(my_param=my_param, **kwargs)

    @staticmethod
    def E_z(z: Union[float, jnp.ndarray], params: Dict) -> jnp.ndarray:
        """E(z) for my model - only define the physics!"""
        z_arr = jnp.asarray(z)
        one_plus_z = 1.0 + z_arr

        Omega_m = params['Omega_m']
        Omega_Lambda = params.get('Omega_Lambda', 1.0 - Omega_m)
        my_param = params.get('my_param', 0.0)

        # Your physics here
        E_squared = Omega_m * one_plus_z**3 + Omega_Lambda * f(my_param)
        return jnp.sqrt(E_squared)

    @classmethod
    def get_parameters(cls):
        """Add my_param to LCDM parameters."""
        from ..parameters import Parameter
        params = LCDM.get_parameters()
        params.append(
            Parameter(
                name='my_param',
                value=0.0,
                free=False,
                prior={'dist': 'uniform', 'min': -1.0, 'max': 1.0},
                latex_label=r'$\xi$',
                description='My custom parameter'
            )
        )
        return params
```

That's it! The decorator handles everything else.
